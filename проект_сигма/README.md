# Проекты SigmaStudio

Открывать `Design1_parker_v0.dspproj`. Он содержит объединённую рабочую цепь внешнего задания и контроля фактического тока. `Design1_parker_transfer_2026-10-27.dspproj` — идентичный снимок при подготовке комплекта.

`Design1_parker_io_calibrated.dspproj` содержит все отдельные калибровки, но предшествует окончательным переподключениям. Остальные `calibrated`, `preliminary` и `before*` сохранены для истории и сравнения. Старые текстовые отчёты тоже описывают соответствующий этап: в них могут упоминаться удалённые позднее ручные источники.

Каталог `IC 1_Design1_parker_v0/` содержит сохранённые результаты компиляции. Они полезны для анализа соединений, но перед живым чтением адресов требуется новая компиляция именно загруженного проекта. Переименование `.dspproj` меняет пути результатов компилятора.

Таблицы TXT содержат только значения равномерно расположенных узлов. Min/Max, фильтры, условия, разветвления и константы нужно брать из `.dspproj` и JSON. Не заменяйте отрицательные коэффициенты выхода на положительные и не обрезайте таблицу входа до 0…1: ограничение нормированного сигнала выполнено отдельными блоками.

Проверка без SigmaStudio: `py -3 tools/sigma/inspect_project.py` из корня пакета. Основные инструкции и статус — в [README](../README.md), [SETUP](../docs/SETUP.md), [STATUS](../docs/STATUS.md).
