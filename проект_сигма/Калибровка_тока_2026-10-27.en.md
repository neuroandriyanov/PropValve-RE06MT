Historical report translated without changing its values. Manual sources mentioned here were removed later; see the [current status](../docs/STATUS.en.md).

The user replaced R43: 180 Ω → 10 kΩ. Working project: `Design1_parker_v0.dspproj`. Reference copy: `Design1_parker_current_calibrated.dspproj`. Fs=96 kHz. The project was loaded into RAM. EEPROM was not written.

`CURRENT_INPUT_0_1` is the 0..1 command input in 5.23 format. `CURRENT_0_3A` is the current-command table, input range 0..1. `ZERO_OFF` makes both DAC0/DAC1 digital commands zero for a command <=0. With a positive command, DAC0=table(x), DAC1=-table(x). `ZERO_CONSTANT` must remain zero.

## Measurement path

`ADC1 -> CURRENT_LPF_20Hz -> FB_LIMIT_MIN -> FB_LIMIT_MAX -> I_FEEDBACK_0_1 -> I_MEAS_0_1`.

`CURRENT_LPF_20Hz` is a first-order 20 Hz low-pass filter with 0 dB gain. `I_FEEDBACK_0_1` is a five-point interpolator: Min=-0.78, Max=0.70. `FB_LIMIT_MIN/MAX` explicitly limit the interpolator input to -0.78..0.70. `FB_MIN_CONST=-0.78` and `FB_MAX_CONST=0.70` must match Min/Max.

`I_MEAS_0_1` is normalized measured current; amperes = value * 3. `ADC1_RAW` is the unsmoothed diagnostic ADC1 signal. No digital regulation loop was closed through `I_MEAS_0_1`; the TL494 analog current controller continued to control the power stage.

After R43 was replaced, no ADC1 saturation was found over 0..3 A: at approximately 3 A, the unsmoothed signal was approximately +0.658 to +0.754. Smoothing reduces reading spread but does not eliminate zero drift. In one calibration series, zero shifted by approximately 0.013 ADC units, equivalent to approximately 26 mA. A fixed table does not compensate for zero changes between series.

This verification describes the board during the measurements, not guaranteed temperature accuracy after cooling/warming. The interpolator itself does not correctly limit values outside Min/Max: before `FB_LIMIT_MIN/MAX` were added, that caused incorrect readings at the ends. Separate blocks now limit the input before the interpolator. Apply `CURRENT_INPUT_0_1` only within its stated 0..1 range.

Full records: historical path `output/meter/feedback_*.json` (now under `measurements/2026-10-27/`). `current_command_0_3A.txt` and `current_feedback_0_3A.txt` contain coefficients only. Min/Max are saved in the project and JSON. DAC3 0..10 V voltage calibration was checked; coefficients were unchanged. At the end, the command was set to zero. Do not rerun the one-off `install_*.py` and `refine_feedback.py` scripts.
