# Измерения

`2026-10-27/` — неизменённые протоколы из исходного `output/meter/`. Итоговые серии: `output_calibration_verification.json`, `feedback_final_verification.json`, `voltage_input_verify.json`. Промежуточные серии также сохранены для воспроизводимости, включая результаты до исправлений и без ограничителей.

Все файлы здесь исторические. Старые время получения, HWND/PID, параметры окон и значения относятся к калибровочному стенду. Калибровки отдельных каналов выполнены до последнего объединения цепи управления. Позднее, в сообщении от 31.10.2026, автор подтвердил, что плата уже работает на машине, прошла испытания и не нагревается. Эти старые серии сохранены как исходные данные калибровки.

Текущие логи записывайте в `output/` (исключён из Git), затем переносите подтверждённую серию в отдельный датированный каталог с описанием платы, нагрузки, подключения, версии проекта и условий измерений. Не перезаписывайте исходные серии.
