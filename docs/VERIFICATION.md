# Проверка подготовленного пакета

Дата: 31.10.2026. Проверка выполнена локально на Windows с Python 3.12 и компилятором .NET Framework. Заявленный минимум Python 3.11 выбран по используемым API стандартной библиотеки; отдельного прогона на Python 3.11 и других ОС не было.

- SHA256 всех перенесённых оригиналов сопоставлены с источниками. Исходные файлы не изменены. Различия есть только в четырёх намеренно адаптированных копиях: `meter.ps1`, `SigmaBridge.cs`, `sigma_api.py`, `capture_node.py`.
- Все 10 `.dspproj` успешно разобраны без запуска SigmaStudio/.NET-десериализации. Рабочая версия и снимок переноса совпадают.
- Четыре таблицы рабочего проекта сверены с текстовыми экспортами; соответствующие таблицы также сверены с JSON-настройками. Базовые константы, наличие индикаторов и отсутствие старых ручных источников проверяются `tools/check_project.py`.
- 7 существующих тестов декодера мультиметра прошли: контрольная сумма, фрагментация кадров, реальные данные, единицы, полярность, непригодные для калибровки режимы и запрет иных команд.
- Переносимый launcher мультиметра проверен через `--help` с явно заданным Python. USB/HID не опрашивался.
- `build_bridge.ps1` успешно собрал C#-исходник. Тестовый EXE оставлен вне поставляемой папки; вызовы сервера SigmaStudio не выполнялись.
- Обработчики отказа настройки регистра захвата и недопустимого числа выборок проверены с подменой API, без оборудования. При отказе настройки последующее чтение не запускается.
- Синтаксис активных Python-скриптов и локальные Markdown-ссылки проверены.

Автор сообщил 31.10.2026, что плата прошла испытания, работает на машине и нагрев платы не наблюдается. Это текущий эксплуатационный статус. Перечисленные выше проверки ассистента относятся к файлам и инструментам; повторное испытание машины ассистентом не проводилось.

- С предыдущим манифестом сверено удаление 54 файлов DipTrace, библиотек и ZIP-дубликата. Прочие файлы до правки документации не изменились.
- Изображение корпуса RUICHI A09 просмотрено и скопировано из исходной папки. Его SHA256 совпадает с оригиналом.
- В документации обновлён статус испытаний и фактический состав папок; добавлено изображение корпуса в README.
- Манифест версии 2 пересчитан по текущему комплекту. Проверены его контрольные суммы, 10 проектов SigmaStudio, 4 таблицы и локальные ссылки.
- Код инструментов не менялся; результаты приведённых выше тестов и сборки относятся к той же версии кода.

Повторить офлайн-проверки можно командами из [инструкции](SETUP.md). `docs/manifest.json` относится к текущей версии подготовленного пакета; новые локальные результаты в `output/` в него не входят.
