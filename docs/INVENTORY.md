## Новые и адаптированные файлы

- `README.md` описывает назначение, вынос платы из зоны нагрева, применение аудио DSP, сигнальные цепи и состав.
- `AGENTS.md` задаёт порядок знакомства с проектом и продолжения отладки ИИ на другом компьютере.
- `docs/SETUP.md`, `docs/STATUS.md` и пояснения в каталогах разделяют актуальную конфигурацию и историю.
- `tools/check_project.py` проверяет контрольные суммы пакета, разбор проектов, согласованность таблиц/экспортов и базовые константы.
- `tools/sigma/inspect_project.py` выводит структурированный отчёт о сохранённом проекте без доступа к оборудованию.
- `tools/meter/meter.ps1` выбирает Python через переменную окружения или PATH, без профиля автора.
- `tools/sigma/build_bridge.ps1` собирает мост штатного API из C# на компьютере пользователя.
- `SigmaBridge.cs`, `sigma_api.py`, `capture_node.py` используют конфигурируемые пути. Для захвата проверяется число выборок и отказ настройки регистра; проверки не пропадают при запуске Python с `-O`.
- `.gitignore` исключает локальные логи, временные файлы, кэш и собранные EXE/DLL. `.gitattributes` сохраняет байты оригиналов и окончания строк для проверки SHA256 после переноса.

## Контрольные суммы

`docs/manifest.json` содержит относительные пути, размеры и SHA256 всех файлов поставки, кроме самого манифеста. Для файлов, происходящих из исходной папки, дополнительно указаны исходный путь, исходный SHA256 и факт изменения при подготовке. Полные пути профиля автора в манифест не записываются.

Манифест фиксирует текущую версию 3 и не обновляется утилитой проверки. Версия 2 учитывала удаление файлов и добавление изображения корпуса, описанные выше. Версия 3 добавляет ссылку на приватный репозиторий и обновляет сведения о размещении; аппаратные файлы, проекты и калибровки не изменены. В метаданных сохранены SHA256 предыдущего манифеста и описание обновления. После собственных изменений несовпадение с этой поставкой ожидаемо и требует осмысленного сравнения. Проверка соответствия таблиц не доказывает правильность всех связей или работы аппаратуры.

Место размещения по поручению автора — приватный репозиторий [neuroandriyanov/PropValve-RE06MT](https://github.com/neuroandriyanov/PropValve-RE06MT). В комплект включено содержимое подготовленной папки; соседние исходные каталоги в загрузку не входят.
