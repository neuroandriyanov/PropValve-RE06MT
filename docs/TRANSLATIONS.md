# Русский оригинал и английский перевод

[Русский](TRANSLATIONS.md) | [English](TRANSLATIONS.en.md)

Русский — исходный авторский язык. Новый материал можно публиковать сразу на русском; английский добавляется после перевода и проверки. Отсутствие или отставание перевода не блокирует русскую публикацию.

## Документы проектов

Сохраняйте русский файл по прежнему адресу. Английскую версию размещайте рядом: `README.en.md`, `docs/SETUP.en.md`. Переводите весь документ, таблицы, подписи и ограничения. В английских документах ссылки на другие документы должны вести на английские версии, когда они есть. Добавляйте явные ссылки между языками. Не меняйте имена команд, API, контактов, регистров и файлов исходных измерений.

Числовые журналы, фотографии, прошивки, CAD и исторические манифесты сохраняются. Для текста внутри схем, графиков и таблиц добавляйте английскую производную копию или точные аннотации с привязкой к оригиналу. Не ретушируйте показания измерительного прибора. Художественная иллюстрация не становится доказательством конструкции.

## Проверка актуальности

Из корня репозитория:

```sh
node tools/translations.mjs status
node tools/translations.mjs status --all
```

`MISSING` — русский документ пока без зарегистрированного перевода; `STALE` — оригинал изменился; `CHANGED` — изменён английский файл после проверки; `BROKEN` — один из зарегистрированных файлов отсутствует. `CURRENT` означает только совпадение сохранённых контрольных сумм, а не автоматическое доказательство качества перевода.

После полного перевода и проверки чисел, единиц, ссылок и технического смысла запишите проверенную пару:

```sh
node tools/translations.mjs record README.md README.en.md
```

Команда сохраняет SHA-256 обоих файлов в `translations.json`. Не запускайте `record` автоматически после изменения русского текста: это скрывает отставание. Обычный `status` сообщает отставание без блокировки русской публикации; `status --strict` требует актуального полного комплекта перед выпуском перевода. Манифест может ограничивать `sourceRoots` и явно перечислять `excludedSources`; исключения должны быть объяснены в документации проекта.

## Страницы сайта

Русский проект остаётся в `src/content/projects/<id>.md`. Перевод добавляется в `src/content/projects/en/<id>.md` с `lang: en`, `translationOf: <id>` и `draft: false` после проверки. Черновой перевод помечается `draft: true`. Русские адреса не меняются; английские имеют префикс `/en/`. Переключатель и языковые метаданные связывают только опубликованные пары. Перевод без опубликованного русского оригинала не выводится.

Общие шаблоны и CSS едины. Тексты интерфейса — `src/i18n/ru.json` и `src/i18n/en.json`. Проверяйте одинаковые ключи, переносы строк и мобильную ширину. Перевод отдельного проекта не требует копировать шаблоны или стили.

Перед выпуском сайта проверяются сборка, ссылки, языковые пары, SEO основной и preview-сборки, ответы НейроИнженера на обоих языках. Публикация GitHub и публикация сайта на хостинге — отдельные действия.
